# Polina

A Russian-inspired birthday page for Polina with wolves, winter light, and a language switch between English and Russian.

The Russian text is intentionally informal and friendly, written with `ты` rather than formal address.

## Open

Open `index.html` in a browser, or use GitHub Pages for this repository.

## Music

Add the song later as:

```text
assets/birthday-song.mp3
```

The music button is already wired for that file.

## Photos

Add future pictures to the `assets` folder with these names:

```text
photo-01.jpg
photo-02.jpg
photo-03.jpg
photo-04.jpg
photo-05.jpg
photo-06.jpg
photo-07.jpg
photo-08.jpg
photo-09.jpg
photo-10.jpg
photo-11.jpg
```

The page will automatically show them when the files exist. Until then, placeholders stay visible.
